# Zilo

原生 macOS 个人清单应用，支持 macOS 14 及以上。界面采用功能导航、清单导航、任务视图和详情四栏布局，可调整栏宽、隐藏导航或详情，并列查看任务和日历。

本仓库包含 macOS 应用源码、Xcode 工程、WidgetKit 小组件、系统分享扩展、测试与中文说明文档。详细完成状态以 [功能验收表](功能验收表.md) 和 [构建报告](构建报告.md) 为准；代码已实现不等于已完成真实账号、双机或真实备份验收。

## 日常使用

- 在任务栏输入 `明天下午3点 写周报 #工作 !3`，回车创建。日期、标签和优先级会自动识别。
- 从左侧进入今天、最近七天、收集箱、清单、标签、过滤器、归档任务、模板或回收站。
- 选择任务，在右侧编辑日期、描述、提醒、重复、检查项、子任务及附件。修改立即保存。
- 查看列表、看板或时间线；拖动任务到清单、分组、看板栏目或日历日期。列表手动排序时可把任务拖到另一个任务前面。
- 日历支持年、月、周、日、日程和课表；四象限按优先级及当天是否到期划分。
- 专注支持番茄钟、正计时、小窗口、补记与历史；习惯支持目标、星期频率、提醒及补打卡。
- 「统计」查看完成任务、专注分钟和习惯达标记录。
- 菜单栏窗口可快速添加任务、完成今日事项并操作专注。应用关闭主窗口后继续在菜单栏运行；用菜单「退出」完全结束。

## 新建和编辑清单

点击清单导航底部「新建清单」，或按 `⌘⇧L`。输入名称，可选择已有文件夹或输入新文件夹；留空放在顶层。分组接受中英文逗号、分号和换行，并整理空白及重复内容。同一文件夹不能重复使用清单名称。

创建成功后自动进入清单、展开所在文件夹并清除原搜索。直接在任务输入框添加任务，即归入当前清单。清单右键「编辑清单」可修改名称、颜色、文件夹和分组；已有任务保持关联。保存失败时保留输入，不关闭窗口；取消或 Escape 不写入数据。

## 数据与权限

本地数据使用 Core Data 保存。每次字段修改记录独立版本，按时间及版本 ID 确定显示值，历史可从任务更多菜单的「任务动态」恢复。回收站删除可恢复，撤销记录保留最近 40 次操作，跨启动不保留撤销栈。

启用 iCloud 需要正确签名和配置 CloudKit。在设置的数据页开启后重启应用。离线继续写入本机，联网后由系统后台同步。附件内容随 Core Data 二进制记录同步。同步同一字段时保留全部历史；检查项数组、标签数组和习惯日志字典作为一个字段处理。

通知、系统日历和提醒事项分别需要系统权限。在设置中主动开启；未授权时不能保证提醒弹出。系统日历可读取，并把选定任务添加为事件；提醒事项按导入方式接入，不是双向同步。

首次运行、每小时及退出时创建当天自动备份，保留最近 30 天。手动备份长期保留。JSON 备份包含任务、清单、习惯、专注和实际附件内容。

**从本地无沙盒构建切换到有沙盒签名构建前，先导出备份，再在新构建中导入。** 两种构建的数据目录不同，原数据不会自动迁移。

## 迁移滴答清单

在滴答清单中导出 CSV 备份，再点击本应用左下角导入按钮。预览显示数量、任务列表和格式警告，确认后才写入，并自动备份现有数据。重复导入按源任务 ID 或稳定内容标识跳过。

已识别的列包括标题、清单、文件夹、标签、描述、日期、优先级、状态、分组、任务 ID、父任务 ID、常用重复规则和提醒。数字状态按 CSV 常用定义 `0 待办 / 1 完成 / 2 归档` 处理；请以你的实际导出文件和预览为准。未知重复及提醒格式会显示警告。CSV 中没有的附件内容、习惯和专注记录无法恢复。

ICS 订阅支持事件、时区、常用日/周/月/年重复以及排除日期。不支持的重复规则会报告错误，不会当作完整导入；重复事件目前展开到未来三年，单规则最多一万次。

## 编译

使用 Xcode 打开 `OwnList.xcodeproj`，选择 OwnList scheme。项目包含主应用、WidgetKit 小组件和系统分享扩展。

- `swift test`：运行模型、数据、迁移与日期测试。
- `scripts/build-local.sh`：生成通用架构本地应用，采用本地临时签名，iCloud 和共享扩展不可用。
- `scripts/archive-release.sh`：使用 Xcode 已登录的开发者账号归档、签名并提交公证。设置 `OWNLIST_TEAM`；Apple 完成公证后再执行脚本提供的导出命令。不要把密码写入源码。

CloudKit 容器：`iCloud.com.gaoluchuan.ownlist`。共享容器：`VFDQL6Z55P.com.gaoluchuan.ownlist`。当前正式应用已签名及公证，但运行时创建 CloudKit 区域失败，尚未完成生产 schema 部署及双机验收。iCloud 不可用时本地数据仍保留；在此问题解决前请用本地模式，并保留手动备份。生产分发前需要把 CloudKit 开发 schema 部署到生产环境。

## 快捷操作

默认全局添加 `⌘⌥A`，设置中支持预设和自定义录制。应用内 `⌘N` 快速添加、`⌘Z` 撤销、`⇧⌘Z` 重做。

URL Scheme：

```text
ownlist://quick
ownlist://add?title=编码后的任务文字
ownlist://task?id=任务UUID
```

该应用为个人 Mac 工具，不包含多人协作、手机和网页客户端、微信或 Notion 账号服务。


### 本轮清单使用变化

新建清单可选择默认列表/看板/时间线；之后切换视图会记住该清单的选择。任务录入框明确目标清单，分组加号先聚焦录入框，输入后回车创建到对应分组。描述直接在详情上部编辑；点击日期按钮配置截止、重复和提醒。⌘F打开搜索，关闭搜索清空条件；已完成任务标题可点击展开/收起。


### 详情编辑使用方式（2026-10-06）

点击任务后，直接在标题下编辑正文，自动保存。默认直接编辑并识别 Markdown；点击右下角 A 显示格式工具栏，在工具栏末尾的编辑设置中选择 Markdown（纯文本）或预览。链接按钮先填写显示文字和地址，再插入正文。

检查项可从标题右侧按钮、正文加号或更多菜单添加；子任务、附件、标签与分组从右下角更多菜单进入。空检查项、子任务和附件区域不占位置；已有内容正常显示。底部清单名称可移动任务。

长正文可在详情区域滚动，顶部日期栏与底部工具保持可见。更多菜单的「打印」打开系统预览，检查后由你选择打印、保存 PDF 或取消。


### 正文与检查项更新（2026-10-06）

短正文后直接显示检查项，正文变长时自动换行并扩展。新增检查项回车保存后继续输入；空白回车或 Escape 退出。已有检查项回车进入下一项，最后一项进入新增输入。多行粘贴按行创建，忽略空白行。

悬停或编辑检查项时出现行菜单，可上移、下移或移除；排序、完成及移除可撤销。检查项拖动尚未通过本轮验证，使用菜单排序。格式工具栏显示选区中的加粗、斜体、下划线等状态。详细对照见《正文与检查项优化报告》。

### 默认 Markdown 输入更新（2026-10-07）

正文默认识别常用 Markdown。行首输入 `##` 再按空格进入标题，`-` 再按空格进入列表，回车继续，空项回车退出；`1.` 支持编号续写。输入 `**文字**`、`*文字*`、`~~文字~~`、反引号代码及 `[文字](https://example.com)` 会直接显示格式。标题回车恢复正文，支持撤销与重做。

每次选中任务默认直接编辑，旧正文打开时不会重写。纯文本 Markdown 入口不提供已有富文本的完整源码转换。支持范围和对照证据见《Markdown默认输入优化说明.md》。

### Markdown 代码块（2026-10-07）

独立一行输入三个反引号，可选语言名，然后回车开始代码块；空代码行输入三个反引号并回车退出。空格、Tab、空行、Markdown符号及中英文按代码原样保留。支持粘贴完整围栏代码块，也可从正文「＋」菜单和格式工具栏插入。语言语法着色尚未实现，详见《Markdown代码块输入修复》。

### 文档贴图、Markdown 文件与导出（2026-10-07）

正文 ⌘V 支持截图、图片和 Finder 复制的 Markdown 文件；也可从正文「＋」插入。读取 Markdown 配套图片时按提示选择其所在文件夹。任务更多菜单「导出文档」支持 Word（.docx）、PDF 和 Markdown（.md）；带图 Markdown 导出为完整文件夹，请一起搬移。图文正文随本机保存，较大正文使用二进制记录；跨 Mac 同步仍待 CloudKit 生产配置及双机验收。详细范围见《文档贴图与导出说明》。

### UI 与颜色调整（2026-10-07）

任务界面使用浅灰导航、白色内容区和柔和蓝色强调；深色模式使用炭灰背景与较亮的文字和清单颜色。顶部视图及更多菜单更紧凑，任务选中项使用中性背景，普通清单不再显示空分组标题。清单导航点击后可用上下键切换，右键编辑、拖动任务归类和新建快捷键保留。设置及清单弹窗直接显示六个颜色按钮。

本轮 41 项回归测试通过，浅色、深色及最终颜色按钮已实机核对。正式应用已完成 Developer ID 签名与 Apple 公证；默认设置已恢复跟随系统和蓝色主题。详细证据与完整功能的剩余事项见《UI界面与配色优化说明》和《功能验收表》。

### 应用正式名称（2026-10-07）

正式名称为 Zilo（原名「知行清单」）。主窗口、菜单栏、关于、小组件、系统分享入口及手动备份文件名统一更新。本仓库提供应用源码，不包含已签名的应用安装包。应用标识、同步容器、数据目录、URL Scheme 和备份格式继续沿用，已有任务及备份兼容。

新 Logo 已用于应用图标、侧栏品牌标记和关于页。图标资源为 Resources/AppIcon-zhixing.icns，透明原图为 Resources/Logo-zhixing.png。本轮正式应用完成 Developer ID 签名及 Apple 公证。
